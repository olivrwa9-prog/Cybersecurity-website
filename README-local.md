# التشغيل المحلي

1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env`، ثم أضف `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` لإرسال الطلبات.
3. من مجلد المشروع شغّل `npm start` وافتح `http://127.0.0.1:3000`.

للوصول من هاتف/جهاز آخر على نفس الشبكة، افتح `http://<ip-الكمبيوتر>:3000` (الخادم يستمع على 0.0.0.0). التوكن محفوظ في `.env` ولا يوضع في HTML. هذا الخادم متاح على جهازك فقط؛ إذا كان الموقع عامًا، يلزم تشغيل الـ API على خادم عام يدعم Node.js وضبط عنوان الطلبات، لكن لا يلزم استخدام Vercel.
